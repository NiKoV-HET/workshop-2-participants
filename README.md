# Workshop 2 — Мультиагентный AI-аналитик в n8n

Материалы участника к 4-часовому интенсиву «Встреча 2». На вход — ваш Telegram-бот с первой встречи. На выход — n8n workflow, в котором 5 AI-агентов собирают для собственника управленческий бриф по проекту перед встречей.

## Кому это

Руководителям, которые прошли первую встречу и хотят собрать рабочую мультиагентную систему руками, без программирования. Все интеграции — нодами n8n; ноль Code-блоков.

## Что внутри

- `docs/participant-guide.md` — пошаговая инструкция на интенсив. Главный файл.
- `docs/snippets.md` — копипаста: промпты, схемы Output Parser, URL, выражения.
- `docs/data-overview.md` — что лежит в трёх проектах датасета (Alpha / Beta / Gamma).
- `prompts/` — резервные копии System Message каждого агента. Источник истины — `docs/snippets.md`, эта папка просто дублирует содержимое для удобства поиска по файлам.
- `workflows/02_starter_workflow.json` — стартовый workflow, импортируется в n8n на старте.

## Как начать

1. Импортируйте `workflows/02_starter_workflow.json` в свой n8n.
2. Дальше идите по `docs/participant-guide.md` — он ведёт от первого блока до финального брифа.

Датасет — три синтетических проекта: **Alpha** (нормальный кейс), **Beta** (неполные данные), **Gamma** (противоречия). Mock API, который их отдаёт, уже запущен у ведущего.

## ⚠️ `workflows/99_reference_final_workflow.json`

Это **эталон собранной системы** — полный готовый workflow со всеми пятью агентами. **Не открывайте его во время интенсива.** Смысл интенсива — собрать систему руками; эталон обесценит вау-моменты. Открывайте после, если застряли и хотите сверить свою сборку, или просто посмотреть, как всё связано в финале.
